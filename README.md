# AgentKit Drawer 🗄️
**Drop-in rules and prompts that make your AI coding agent behave from the first prompt.**
Cursor, Claude Code, Codex and Windsurf guess your stack and conventions when they have no instructions. These packs give them that context.

| [`free/agent-guardrails.md`](free/agent-guardrails.md) | Prompt-injection defense, ask-vs-act and citation snippets for any agent | Any system prompt |
