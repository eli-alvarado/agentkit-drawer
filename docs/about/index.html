About AgentKit Drawer

AI coding agents are fast and confident, and they don't know your stack. They disable row-level security to "fix" an error, call an API from three versions ago, or rewrite your player controller at hour 47 of a game jam.

AgentKit Drawer makes the boring fix: short, scoped rules files (AGENTS.md, CLAUDE.md, .cursor/rules) and prompt templates for one stack at a time, so the agent follows your conventions from the first prompt.

How we work

  • Free first. A sample from every pack is MIT-licensed on GitHub.
  • Honest labels. Pack pages say what has and hasn't been tested in each tool.
  • One-time price. No subscription. Updates for the version you bought.

Who's behind it

AgentKit Drawer is a small independent shop based in Texas, USA, run by Eli Alvarado with AI agents doing a lot of the building (yes, using these rules). Questions, ideas or bugs: agentkitdrawer@agentmail.to.
