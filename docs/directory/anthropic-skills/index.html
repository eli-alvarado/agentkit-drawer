Anthropic's skills repo: SKILL.md examples and a template

CLAUDE CODEANY STACK

By Anthropic · License: Mixed: many examples Apache 2.0; document skills are source-available, not OSS

If you are going to write a Claude Code skill, this is the repo that defines the folder shape. It is a teaching set, and Anthropic says so.

Open Anthropic Agent Skills

What it does

A skill is a folder with a SKILL.md file: YAML frontmatter (name, description) plus instructions Claude loads when the task matches. The repo has a template, a spec pointer, and example sets for creative work, technical tasks, enterprise comms and documents.

You can add it as a Claude Code marketplace (/plugin marketplace add anthropics/skills) and install document-skills or example-skills. The same examples appear for paid Claude.ai plans. The API can upload custom skills.

The README's disclaimer matters: implementations in the product may differ, and the skills are for demonstration. The docx/pdf/pptx/xlsx skills are source-available reference for production document code, not Apache 2.0.

Who it is for

People authoring skills or plugins who need a correct SKILL.md. Also anyone who wants to see how Anthropic splits a large capability (PDF) into a skill folder instead of a giant CLAUDE.md.

Not a substitute for project memory. A skill that generates an MCP server will not tell Claude how your FastAPI app runs tests.

Our take

First-party examples are the right place to learn the format. The template is small. The document skills are the rare look at a skill that ships in the product.

The limit is purpose. Many examples are not software-engineering workflows. The repo will not give you a code-reviewer subagent or a hook that blocks force-push. Mixing Apache 2.0 examples with source-available document skills also means you should read the license in the folder you copy.

The Agent Skills standard is documented separately at agentskills.io; this repo is Anthropic's implementation and samples.
