awesome-cursorrules: a large public pile of Cursor .mdc files

awesome-cursorrules is the collection most people find first when they search for Cursor rules. It is a library, not a single opinionated kit.

Open awesome-cursorrules

What it does

The repository collects community Cursor rules, mostly as .mdc files meant for .cursor/rules/. There is a large rules/ tree and a smaller rules-new/ set. Entries range from Next.js and FastAPI to Cypress, Flutter, clean-code slogans and one-off product prompts.

You pick a file that looks close to your stack, copy it into your repo, and keep the YAML frontmatter Cursor needs (description, globs, alwaysApply). The project documents the shift away from a single root .cursorrules file toward scoped project rules.

Because the license is CC0, reuse is easy. That also means there is no central quality bar. Files are contributed at different times, for different Cursor versions, and they are not a supported product.

Who it is for

Cursor users who want examples before writing their own rules. If you have never seen a glob-scoped .mdc file, reading three or four from this repo is useful.

It is a poor fit if you expected a maintained pack for one stack. There is no installer, no test suite, and no promise that the Next.js file matches the App Router version you are on.

Our take

The breadth is the reason this repo stays useful. You can see how other people phrase a FastAPI rule or a testing rule and steal the shape, not the whole file.

The limit is quality drift. Some files still read like Next.js 14 blog posts. Some are generic "write clean code" lists that waste context. A few are marketing prompts for a specific SaaS. Always read the file, cut it down, and pin versions that match your repo.

We would not drop an entire folder from this collection into a production app. One or two scoped files, edited, is the honest use.
