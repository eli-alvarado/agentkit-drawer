awesome-mcp-servers: the community index, not a server you run

MCPANY

By punkpeye and contributors · License: MIT

This repository is a list. It will not start an MCP process. It is still the map most people use when they ask "is there a server for X?"

Open awesome-mcp-servers

What it does

The README catalogs servers by category with links out. The project homepage points at a hosted browser (glama.ai/mcp/servers). Entries appear, move and go stale the way all Awesome lists do.

The official MCP GitHub org now tells people to use the MCP Registry for published servers and keeps only reference implementations in modelcontextprotocol/servers. This list remains the broader, messier community view.

MIT covers the list text, not the licenses of the servers it links to.

Who it is for

Someone shopping for a connector: browser, docs, issue tracker, database. Also useful when a blog post names a server and you want the upstream link.

Do not clone it as a dependency. Do not install a server from a list row without opening the source repo and checking auth.

Our take

As a phone book it still works. Official servers for GitHub, Stripe, Playwright and Context7 are easier to find when you already know the name.

The limit is the format. Lists accumulate abandoned servers, duplicate unofficial wrappers and rows that never mention write access. A star sort (on any mirror) is not a security review. We will not quote star counts.

Prefer vendor docs once you know the product. Use this list only for discovery, then pin the server version you actually run.

Compared with AgentKit Drawer

We are a rules shop, not an MCP index. This directory page exists so you can find the index without us pretending we reviewed every server on it.

No pack CTA. If you came here looking for agent instructions, go back to AGENTS.md or a stack pack. If you came here looking for a connector, follow a link and read that server's README.
