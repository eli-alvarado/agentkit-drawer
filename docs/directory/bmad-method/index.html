BMad Method: agile skills that try to hold context across a project

CLAUDE-CODECURSORCODEXANY

By BMad Code · License: README states MIT

BMad is a process you install, not a CLAUDE.md. It wants decisions written down so the next agent session is not guessing why the last one built a second auth system.

Open BMad Method

What it does

The method adds named skills to tools such as Claude Code and Cursor. Some skills are for thinking: clarify, research, argue, write the brief. Others are for building: bmad-build takes a change and works it. Docs live at docs.bmad-method.org.

Two lines exist as of our check. Stable v6.12 installs with npx bmad-method install and is described as frozen aside from bug fixes. V7 is preview alpha on the default branch: npx skills add bmad-code-org/BMAD-METHOD --skill '*', plus Claude Code and Codex marketplaces under bmad-code-org/bmad-plugins. The README says v7 skills and docs change often.

Setup writes project files (v7 mentions _bmad/ and _bmad-output). This is a bigger footprint than a single rules file.

Who it is for

People who want an agentic SDLC: briefs, plans, architecture notes, then implementation. Teams that lose context between chats are the intended user.

Too much ceremony for a weekend jam or a one-file script. If v7's moving pieces would break your week, the README tells you to stay on v6.12.

Our take

The useful idea is that coding quality dies when the plan lives only in a chat transcript. Forcing artifacts is a real answer to that.

The limit is weight and churn. Preview v7 can break setups. The method will not know your Stripe webhook rules or your Godot InputMap policy. You still need project-specific never-dos.

GitHub's SPDX field was empty when we looked; the project README marks MIT. Check the license file in the branch you install.
