Anthropic's official Claude Code plugin directory

CLAUDE-CODEANY

By Anthropic · License: Apache-2.0

This repository is the marketplace Claude Code already knows. Superpowers and other well-known plugins show up here. That does not make every plugin safe.

Open Claude plugins official

What it does

The repo splits /plugins (Anthropic-maintained) and /external_plugins (partners and community). Install with /plugin install {name}@claude-plugins-official or from Discover. Plugin names are immutable slugs; renaming breaks existing installs unless a renames map is added.

A plugin can include commands, agents, skills, and an optional .mcp.json. Skill-bundle entries can list SKILL.md folders without a full plugin.json.

The README warning is unusually plain: Anthropic does not control what MCP servers or other software a plugin includes and cannot verify that plugins will work or will not change. Trust is still your job.

Who it is for

Claude Code users who want the supported install path instead of copying files by hand. Also plugin authors who need the official layout and the submission form for external plugins.

If you do not use Claude Code, this repo does nothing for you.

Our take

Having a first-party directory is better than random gists. Internal plugins have a reference implementation. External plugins at least passed a listing bar.

The limit is the warning they wrote themselves. A marketplace install can still pull an MCP server that writes to GitHub or Stripe. Review the plugin homepage and the MCP config before you enable it on a repo with secrets.

We list this because it is the real distribution channel, not because we endorse every plugin in it.
