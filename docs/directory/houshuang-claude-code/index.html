A small Claude Code marketplace built from real sessions

CLAUDE CODEANY STACK

By houshuang · License: License not clearly declared on the GitHub repo

Unlike a giant Awesome list, this repo is itself a plugin marketplace. Each hook, skill, command and agent installs on its own.

Open houshuang/awesome-claude-code

What it does

Inside Claude Code: /plugin marketplace add houshuang/awesome-claude-code then /plugin install pr-walkthrough@awesome-claude-code (or another name). Components are namespaced. You can also copy folders into ~/.claude/skills or .claude/commands.

The README lists a finite set: hooks that block commits to main and lint after edits, skills for PR walkthroughs and Playwright, commands like /commit and /catchup, plus a few agents. Several rows are marked superseded because Claude Code grew a native equivalent.

That "superseded, not deleted" habit is the interesting editorial choice. The catalog is allowed to shrink in usefulness as the product catches up.

Who it is for

Claude Code users who want one hook they have read, not a 90-plugin marketplace. The prevent-main-commit and post-edit-lint hooks are the obvious first installs.

If you need a full CLAUDE.md plus subagent suite, this is only a supplement.

Our take

Small and honest beats large and stale. Marking superseded items is more trustworthy than silently leaving dead commands in a list.

Limits: no clear GitHub license when we checked, so copy/paste legal status is fuzzy. Namespacing makes installed commands longer. A few skills are frontend- or PR-documentation flavored, not backend-safety flavored.

We have not run the author's session count and we will not repeat it as a metric. The value is the finite list and the superseded labels, not a usage brag.

Compared with AgentKit Drawer

Our hooks guide and Claude Code Kit cover secret protection, rm -rf, and tests on Stop. This marketplace covers commit hygiene and a handful of workflow skills. Overlap is small.

Install their prevent-main-commit hook next to our settings.json hooks if both match how you work. Do not install both code-reviewer agents and then wonder which one ran.
