04FAQ

  
Which tools does it work with?
Cursor, Claude Code, Codex CLI, Windsurf, Aider, and anything that reads AGENTS.md. Each pack ships the tool-specific files too.

  
Are these tested?
They're written against each tool's documented conventions, and the Agent Builder pack includes evals you can run on your own model. We haven't benchmarked them against a reference project yet. If a rule misbehaves, tell us and we'll fix it in an update.

  
Why not write my own rules?
You can, and the free files on GitHub are a good start. The packs save you the hours of finding out what agents get wrong: RLS, webhook trust, scene-tree rewrites, injection.

  
Updates?
