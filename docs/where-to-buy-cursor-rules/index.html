Free places to get Cursor rules

  • Cursor Rules docs - Official docs for project rules (.cursor/rules/*.mdc), User Rules, Team Rules and AGENTS.md. Best starting point if you want to write your own.
  • cursor.directory - Community directory of Cursor plugins and rules, ranked by installs. Free to browse; many entries are free community rulesets (for example Next.js, FastAPI, Expo).
  • awesome-cursorrules - Large CC0 GitHub collection of community .cursorrules / .mdc files by stack. Good for browsing patterns; quality varies by contributor.
  • RuleSell - Marketplace-style catalog that quality-scores .cursorrules and .mdc files. The React Developer Starter Bundle on the catalog page was listed as Free when we checked.

FAQ

Should I buy Cursor rules or write my own?

Write your own (or fork a free GitHub set) if your conventions are unique. Buy a pack when you want a maintained starting point for a common stack and would rather skip the first week of rule-tuning.

Are free Cursor rules on GitHub safe to use?

Treat them like any dependency: read the files, check how recent they are, and drop rules that do not match your stack. A popular repo is not the same as a reviewed kit.

What format should I install?

Prefer .cursor/rules/*.mdc with frontmatter (description, globs, alwaysApply). Cursor's docs still mention the legacy single-file .cursorrules format; newer packs usually ship both.
